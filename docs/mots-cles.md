## 8. Méthode

1. **Audit Search Console + Ahrefs** à T0 pour collecter les volumes réels (les chiffres ci-dessus sont des ordres de grandeur).
2. **Mapping URL ↔ mot-clé principal** : 1 URL = 1 mot-clé principal + 5 à 15 secondaires sémantiquement proches. Pas de cannibalisation.
3. **Brief rédactionnel** par page : intention, plan H2/H3, FAQ, longueur cible (minimum 800 mots pour catégorie, 1 500 mots pour guide, 2 500+ pour les guides piliers).
4. **Tracking hebdo** des positions sur les 200 mots-clés prioritaires via Ahrefs Rank Tracker.
