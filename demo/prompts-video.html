Specs techniques pour le hero web

À demander à l'IA, ou à appliquer en post-production via HandBrake / ffmpeg.

FormatMP4 (H.264) + WebM (AV1) en fallback
Ratio16:9 ou 21:9 (cinéma)
Durée5 à 8 sec, en boucle
Poids< 2 Mo (compressé)
Résolution1920×1080 max
Bitrate2-3 Mbps
SonAucun (muet autoplay)
Poster JPGPremier frame, pour LCP

Réglages Kling AI — obligatoires pour le hero

  • Modèle : Kling 2.1 Master (ou 2.0 si 2.1 indispo). Pas Kling 1.6 ni Standard.
  • Mode : Pro Mode obligatoire. Standard rate les objets précis comme un matelas.
  • Ratio : 16:9. Durée : 5 sec.
  • Negative prompt (à coller dans le champ Advanced) :
    people, person, human, text, watermark, logo, blurry, distorted, deformed, low quality, ugly, dirty, wrinkled, crumpled, oversaturated, glitch, weird anatomy

Astuces générales

  • Génère 1 version d'abord, regarde le résultat. Si bon → on s'arrête. Si OK → utilise « Vary » plutôt que de tout regénérer (économie de crédits).
  • Si raté → change 1 mot du prompt seulement (ex : sunset → sunrise, pink → lavender) et relance.
  • Évite le Master Mode pour les premiers tests, garde-le pour la version finale.
  • Avant d'uploader : compresse avec HandBrake en H.264 / 2 Mbps. Cible : < 2 Mo, 1920×1080.
  • Génère une image JPG du premier frame pour le LCP (Core Web Vitals).
