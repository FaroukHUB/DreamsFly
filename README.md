# DreamsFly

E-commerce de matelas — livraison dans toute la France.

## Mission

Devenir la référence française du matelas en ligne en combinant :

- **Qualité produit** (gammes mousse, ressorts, hybride, latex, mémoire de forme).
- **Expérience d'achat sans friction** (essai 100 nuits, livraison offerte, garantie longue durée).
- **Excellence SEO** : structure technique irréprochable, contenu d'expert E-E-A-T, données structurées exhaustives.

## Objectif SEO

Top 3 Google sur les requêtes commerciales principales (« matelas », « matelas mémoire de forme », « meilleur matelas », « matelas 140x190 », etc.) sous 12 mois.
